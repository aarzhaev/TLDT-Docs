The fastest useful setup is a small, reviewed public profile. You can add more detail later.

<Steps>
  <Step title="Create your account">
    Open [TLDT](https://tldt.me) and choose **Sign up**. You can use an email Magic Link/OTP or Google. After sign-in, choose an available username. This username becomes your public profile address.
  </Step>
  <Step title="Open Memory → Import Guide">
    The Import Guide explains what to prepare. Start with a CV, project notes, work history, or interview transcripts that you own and trust. Upload Markdown or text files to Raw Memory.
  </Step>
  <Step title="Review Properties and choose what is public">
    For every useful file, review its title, summary, topics, use-when hint, visibility, and sensitivity. Mark a file **Public** only when you are comfortable using it in recruiter conversations. Private files stay in your owner workspace.
  </Step>
  <Step title="Preview and publish Memory">
    Open the publication preview, read the exact files and warnings, then publish a version. Activate that version when it should power your public profile. Draft edits do not change the live profile by themselves.
  </Step>
  <Step title="Set up the public link">
    In **Settings**, customize the public copy, starter prompts, language, optional visitor validation, interpretation, Public CV, and social links. Turn on the public link and use **Copy link**.
  </Step>
  <Step title="Test the visitor experience">
    Open **Public page** in a private browser window. Ask a representative question, try Fast Check with a real vacancy, and open the Public CV if you enabled it. Use [Owner Preview](/owner-review/preview) for a private test that does not add a visitor transcript.
  </Step>
</Steps>

<Note>
  Start with evidence you can explain. A short, accurate profile is more useful than a long profile with claims you would need to correct later.
</Note>
