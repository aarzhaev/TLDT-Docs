Start with one real vacancy or interview. Build only enough reviewed Career Memory to support an honest first check; add more evidence when the work exposes a real gap.

<Steps>
  <Step title="Create your account">
    Open [TLDT](https://tldt.me) and choose **Sign up**. Use an email Magic Link/OTP or Google, then claim an available username.
  </Step>
  <Step title="Add the smallest useful evidence set">
    Open **Memory → Import Guide**. Start with a CV and the project, role, or interview notes most relevant to the role you want to check. Upload only material you own and can verify.
  </Step>
  <Step title="Review documents and Properties">
    Check content, title, summary, topics, retrieval hints, visibility, sensitivity, and any special role. **Public** means eligible for publication; it does not mean live. Private documents stay in the owner workspace.
  </Step>
  <Step title="Publish and activate a Memory version">
    Review the exact publication contents and warnings. Publish an immutable version, then activate it. Fast Check, Auto Simulate, Preview, and the public profile never read directly from an editable draft.
  </Step>
  <Step title="Run Fast Check with the real role">
    Open **Preparation → Fast Check**, paste one substantive vacancy link or description, review the extracted role, and run the diagnostic. Read strengths, partial coverage, real gaps, missing proof, and questions to validate.
  </Step>
  <Step title="Choose Manual or Auto Simulate">
    Use **Manual** to rehearse your own answers. Use **Auto** to test what the pinned published AI profile can answer. Both modes use the same vacancy and produce a report you can review.
  </Step>
  <Step title="Review, improve, and share selectively">
    Correct Memory through the normal draft and publication flow. You may explicitly save a useful Chat or Simulate transcript to Raw Memory for review. Turn on the public link or create a saved share only when another person needs access.
  </Step>
</Steps>

<Warning>
  TLDT does not build a complete Career Memory automatically from arbitrary files. Generation creates reviewable drafts, and saving a session to Raw Memory never edits Derived Memory or publishes anything by itself.
</Warning>
