<AccordionGroup>
  <Accordion title="What is TLDT?">
    <p>TLDT is an owner-controlled Career Memory and AI representative. It helps a person check a real role, prepare and practice for interviews, and selectively let recruiters explore the same reviewed professional context.</p>
  </Accordion>

  <Accordion title="What should I do first?">
    <p>Start with one real vacancy or interview. Create a small accurate Memory, publish and activate it, then run Fast Check. Use Manual Simulate to rehearse your own answers or Auto Simulate to test the published AI profile.</p>
  </Accordion>

  <Accordion title="Do I need published Memory before Fast Check or Simulate?">
    <p>Fast Check and Auto Simulate need usable published Memory. A simulation created without active Memory remains Manual-only. Draft documents never act as a hidden runtime fallback.</p>
  </Accordion>

  <Accordion title="How is Fast Check different from keyword matching?">
    <p>Fast Check is an evidence-aware diagnostic. It can separate supported fit, partial coverage, a real requirement gap, and missing proof in published Memory. It does not reduce the role to a keyword score or make a hiring decision.</p>
  </Accordion>

  <Accordion title="What is the difference between Manual and Auto Simulate?">
    <p>Manual asks, “How would I answer?” You write each candidate response. Auto asks, “What can my published AI profile answer?” TLDT responds from the Memory version pinned to the session. Interview style—Realistic or Diagnostic—is a separate setting.</p>
  </Accordion>

  <Accordion title="Does every session improve my Memory automatically?">
    <p>No. You may explicitly save a useful Chat or Simulate transcript to Raw Memory. That action preserves a source for review; it does not extract a structured Memory Delta, edit Derived Memory, or publish anything automatically.</p>
  </Accordion>

  <Accordion title="Can TLDT build my complete Career Memory from arbitrary files?">
    <p>No. You choose and upload supported source material. Properties analysis and Derived generation can help organize selected evidence, but every generated result remains a reviewable draft and starts Private.</p>
  </Accordion>

  <Accordion title="Can visitors see Private Memory or drafts?">
    <p>No. Public routes use only the active published projection. Private files, editable drafts, source paths, prompts, internal citations, provider metadata, policy reasons, and tool traces stay outside public responses.</p>
  </Accordion>

  <Accordion title="Can TLDT apply, negotiate, or commit for me?">
    <p>No. TLDT can explain evidence, help prepare a conversation, and offer a visible scheduling flow when configured. It cannot apply, accept or reject a role, negotiate, promise interest or availability, or make other commitments for the owner.</p>
  </Accordion>

  <Accordion title="Is TLDT a live interview copilot?">
    <p>No. Simulate is a preparation workflow, not a hidden real-time assistant during a live interview. Voice input, when available, transcribes into an editable composer and never sends automatically.</p>
  </Accordion>

  <Accordion title="Can I revoke a shared result?">
    <p>Yes. A saved Chat, Fast Check, or Simulate share has its own capability link. Revoking the link disables that public snapshot without deleting the underlying owner resource.</p>
  </Accordion>

  <Accordion title="Is Fast Check a hiring prediction?">
    <p>No. It is a structured preparation and conversation aid. It does not verify identity, predict interview outcomes, rank candidates, or replace a human decision.</p>
  </Accordion>
</AccordionGroup>
