TLDT helps you find relevant roles, check your fit, and prepare for interviews using your real career experience. The useful examples you add along the way become reviewed Career Memory that you can reuse for the next opportunity and, if you choose, share through an AI representative.

## Your path through TLDT

1. **Sign in and add your CV** in Profile.
2. **Bootstrap your Memory.** If ChatGPT or Claude already knows your professional history, use Import Guide to export that context as Markdown files. Review them in TLDT and publish the evidence you approve.
3. **Prepare Search Profile and find jobs.** Use Job Search and Instant Fit to identify roles worth a closer look.
4. **Check one vacancy with Fast Check**, then run **Auto Simulate** to see what your twin can answer from the published evidence.
5. **Fill the gaps.** Practice in Manual Simulate, or answer a Memory Gap directly with text or dictation.
6. **Review proposed Memory changes and publish.** Repeat the loop as new questions and experience arise.
7. **Share when ready.** Test in Preview, enable your Public link, add professional links, and optionally connect Cal.com meetings.

Follow the [get-started walkthrough](/quickstart) for the exact actions. You can use private search and preparation before enabling the public link.

## Memory stays under your control

Your evidence, editable drafts, published versions, and session results serve different purposes. Generated changes need review. Accepting a Memory Loop proposal changes a draft; **Publish** makes the reviewed version active. Enabling the public profile is a separate choice.

A gap in stored evidence is not proof of a gap in your experience. TLDT helps you identify what needs explanation without inventing a stronger career history or making commitments for you.

If you received someone else's link, start with [Public representation](/public-profile/overview). For the relationship between the workflows, see [How TLDT works](/how-tldt-works).
