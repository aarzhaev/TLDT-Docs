# Product brief

Updated: 2026-11-07.

## Description

TLDT helps people build reviewed Career Memory, find relevant vacancies, assess
fit, rehearse interviews, retain useful answers, and optionally share an AI
representative. Career Memory is the lasting asset; the twin is one way to use it.

## Primary audience

Professionals starting or continuing a job search, followed by visitors who have
received a person's TLDT link. Preserve the established English documentation
and existing visual design. Describe ordinary owner and visitor capabilities;
exclude service-administration features and internal implementation details.

## Jobs to be done

1. Sign in, add and review a CV, and bootstrap Memory through the Import Guide's
   ChatGPT/Claude prompt when the assistant already has useful career context.
2. Publish reviewed Memory, prepare Search Profile, and use Job Search and
   Instant Fit to choose a vacancy for Fast Check and Simulate.
3. Answer Memory Gaps with text, dictation, or verified Manual Simulate answers;
   generate, review and accept proposed changes into a draft, then publish.
4. Test representation, enable the Public link deliberately, share selected
   results, and optionally connect Cal.com meetings.

## Motivation

Reuse the evidence behind a CV instead of reconstructing career examples for
each opportunity. Missing stored evidence is not proof of missing experience.
Review and publication remain separate from generation. Publishing Memory in
the workspace activates a version; enabling the public profile is a separate
choice. External assistant connectors and employer discovery are not released
features. Do not turn strategy, demo copy or pricing hypotheses into promises.
