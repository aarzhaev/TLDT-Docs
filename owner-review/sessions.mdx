## title: "Sessions and summaries" description: "Review visitor Chat and public Fast Check activity from the owner workspace."

Open **Sessions** to review two kinds of visitor activity:

- **Chat** sessions with the visitor's messages and TLDT replies;
- **Fast Check** sessions with the vacancy and completed fit report.

## Review a Chat session

The detail view can show safe visitor context, the conversation, answer provenance, validation state, and whether owner review is needed. Internal prompts, policy reasons, provider metadata, source paths, and tool traces are not part of the visitor-facing content.

You can:

- read the transcript;
- generate or refresh a session summary;
- save a transcript or summary to Raw Memory for later review;
- create or revoke a visitor-safe share;
- delete the session.

Saving to Raw Memory is an explicit owner action. It gives you a source to review; it does not publish the conversation automatically.

## Review a Fast Check

The Fast Check list shows completed public checks separately from Chat. Inspect the vacancy evidence, report tabs, and share state. Use **Check again** when you want a new immutable check; the previous report remains unchanged.

<Warning>
  Visitor content is untrusted context. Review it before using it as Raw Memory, especially when it contains claims about a company, role, or person.
</Warning>
