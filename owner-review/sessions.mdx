Open **Public Link → Sessions** in the sidebar to review [public Chat](/public-profile/chat) and [public Fast Check](/public-profile/fast-check#use-fast-check-from-a-public-profile) activity. Switch between the **Chat** and **Fast Check** views, then select a session. Private preparation sessions remain in their respective [Fast Check](/public-profile/fast-check#run-an-owner-fast-check) and [Simulate](/owner-review/simulate#set-up-an-interview) histories.

## Review public Chat

A Chat detail view can show visitor context, the conversation, answer labels, validation state, and whether owner attention may be useful. Thumbs-up and thumbs-down badges show [feedback left by the visitor](/public-profile/chat#give-feedback-on-an-answer) on individual twin replies.

The owner can:

- read the transcript;
- generate or refresh an owner-only session summary;
- save the transcript, with an available current summary, to [Raw Memory](/memory/drafts-and-documents#raw-and-derived-serve-different-jobs) for later review;
- use **Export .md** to download the conversation;
- [create or revoke a visitor-safe share](/sharing);
- delete the session.

Open **Session Summary**, choose English or Russian, and use **Generate summary**. Use **Regenerate** if new messages make the saved summary out of date. The summary can be copied; an outdated summary is not included in the transcript's Memory save or Markdown export.

Review the complete conversation before sharing it. Visitor-facing snapshots omit internal information, but can still contain personal details a participant typed.

## Review public Fast Check

Fast Check sessions appear separately from Chat. Inspect the vacancy, extracted context, report, evidence, questions, and share state.

Use **Check again** when you need a new immutable diagnostic. The previous completed report remains unchanged.

Completed checks can also have owner-only [Memory Gaps](/memory/gaps). Review those findings in their source context before answering them or changing Memory. The result menu offers Markdown export, share management, and deletion.

## Reuse requires owner review

Saving a Chat transcript, summary, or simulation to Raw Memory is an explicit owner action. The saved material becomes a source to inspect; it does not:

- make visitor claims true;
- change Derived Memory;
- turn a twin or visitor statement into your own verified testimony;
- publish a new Memory version;
- update an existing report or simulation.

For a structured improvement, [save your own answer to a Memory Gap](/memory/gaps#add-your-answer), then use [Memory Loop](/memory/loop) to generate and review proposed changes. Public Chat feedback and transcript saves do not run that flow automatically.

<Warning>
  Visitor content is untrusted context. Check claims about a company, role, person, date, or outcome before keeping them as evidence.
</Warning>
