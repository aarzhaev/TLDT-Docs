Sessions let the owner review public Chat and public Fast Check activity after visitors interact with the profile. This review supports follow-up, evidence maintenance, and selective sharing without turning visitor content into trusted facts automatically.

## Review public Chat

A Chat detail view can show safe visitor context, the conversation, answer provenance, validation state, and whether owner attention may be useful.

The owner can:

- read the transcript;
- generate or refresh an owner-only session summary;
- save the transcript or summary to Raw Memory for later review;
- create or revoke a visitor-safe share;
- delete the session.

Internal prompts, policy reasons, provider metadata, source paths, tenant identifiers, and tool traces are not part of visitor-facing content.

## Review public Fast Check

Fast Check sessions appear separately from Chat. Inspect the vacancy, extracted context, report, evidence, questions, and share state.

Use **Check again** when you need a new immutable diagnostic. The previous completed report remains unchanged.

## Reuse requires owner review

Saving a Chat transcript, summary, or simulation to Raw Memory is an explicit owner action. The saved material becomes a source to inspect; it does not:

- make visitor claims true;
- change Derived Memory;
- compare Manual and Auto answers automatically;
- publish a new Memory version;
- update an existing report or simulation.

<Warning>
  Visitor content is untrusted context. Check claims about a company, role, person, date, or outcome before keeping them as evidence.
</Warning>
