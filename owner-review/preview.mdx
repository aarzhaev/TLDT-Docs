## title: "Owner Preview" description: "Test the public representation privately before you publish or send the link."

**Preview** is an owner-only Chat surface. It uses the same published-Memory boundary as the public profile but does not append a visitor transcript.

## Use Preview for a release check

Ask the questions a recruiter is likely to ask:

- What did you personally own?
- Which project best demonstrates the requested skill?
- What evidence supports this result?
- What is still unclear or outside the profile?

Check that the answer is accurate, appropriately scoped, and clear in tone. Review provenance labels and make sure the response respects your Boundaries.

## Preview does not replace publication review

Preview tests the current published runtime. It does not make draft edits live and it does not substitute for the [Memory publication preview](/memory/publish). If the answer needs new context, edit the draft, publish a new version, and activate it.

<Tip>
  Use Preview after every meaningful Memory release. A representative question catches unclear summaries and missing evidence before a recruiter sees them.
</Tip>
