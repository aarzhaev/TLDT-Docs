Owner Preview tests the current public representation without creating a visitor transcript. It uses the same active published Memory boundary as Public Chat.

Open **Public Link → Preview** in the sidebar. You can test while your Public link is off. Type a question or dictate into the composer, review the text, and send it. Use the available language and model controls when needed.

## Use Preview before you share

Ask questions that reveal whether the profile is accurate and appropriately scoped:

- Which experience supports this requirement?
- What did I personally own?
- Which project best demonstrates the requested skill?
- What evidence supports this result?
- What is missing or outside the published profile?
- Could this answer imply interest, availability, or a commitment that I did not make?

Review the answer's facts, scope, tone, and provenance labels. Check that Boundaries are respected and that uncertainty remains visible.

## Preview tests the active version

Preview does not read editable drafts and does not replace the [publication preview](/memory/publish). If an answer needs different evidence:

<Steps>
  <Step title="Return to the draft">
    Correct the source or Derived explanation in the owner workspace.
  </Step>
  <Step title="Review the publication">
    Check the exact files, roles, sensitivity warnings, and version diff.
  </Step>
  <Step title="Publish the reviewed draft">
    Confirm Publish in Memory to create and activate the new immutable version.
  </Step>
  <Step title="Test again">
    Repeat the representative questions in Owner Preview.
  </Step>
</Steps>

## Preserve a useful test

Use **Save to Raw Memory** if you want to keep the Preview transcript for later review. This is an explicit source save, not a Memory Loop proposal or a publication. Review the text before treating anything in it as personal evidence.

Preview does not produce the same automatic gap analysis as completed Fast Check and Simulate sessions. Use [Analyze in Memory](/memory/gaps) or those preparation workflows when you want saved gap cards.

<Tip>
  Use Auto Simulate when you need a harder role-specific test. Preview checks ordinary public questions; Auto Simulate tests the profile inside a structured interview.
</Tip>
