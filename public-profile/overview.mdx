## title: "Public profile overview" description: "Learn what a visitor sees on a TLDT profile and which next steps are available."

A public TLDT profile is a shareable page at `tldt.me/your-username`. It gives a recruiter a short introduction, a controlled Chat, an optional Public CV, and Fast Check when the owner has enabled them.

## Public page areas

<CardGroup cols={2}>
  <Card title="Chat" icon="message-circle" href="/public-profile/chat">
    Ask about experience, projects, working style, or a role.
  </Card>

  <Card title="Fast Check" icon="briefcase-business" href="/public-profile/fast-check">
    Compare a vacancy with the published profile context.
  </Card>

  <Card title="Public CV" icon="file-text">
    Open the owner-approved CV when it is enabled.
  </Card>

  <Card title="Meeting" icon="calendar">
    Request a meeting form when the owner has connected scheduling and the conversation qualifies.
  </Card>
</CardGroup>

## Before you start

The owner chooses which Memory version is live and which public features are enabled. The page may also show starter prompts, social links, a language switch, a theme switch, or a visitor validation form.

<Tip>
  Use the starter prompts when you want a quick first question. They are prompts, not required steps.
</Tip>

## Public boundaries

The page never exposes the owner's Private Memory, draft content, source paths, prompts, internal citations, policy reasons, provider details, or tool traces. A saved view can show a strict snapshot of a completed Chat, Fast Check, or Simulate resource without opening the owner's workspace.
