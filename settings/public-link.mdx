Manage your public representation in **Profile** from the owner sidebar. You can prepare its copy and settings while the Public link is off, then enable it after testing the active Memory in [Preview](/owner-review/preview).

## Set the address and enable the link

Choose an available username for your address, such as `tldt.me/your-username`. An active published Memory version is required before the public profile can be enabled.

Turn on **Public link** and use **Save changes**. **Copy link** copies the address; **Public page** opens it for inspection. Turn the link off and save to stop public-profile access without deleting your Memory.

Publishing Memory and enabling the link are different actions. New Memory publications can change the active evidence behind an already-enabled profile, so review each publication carefully.

## Add an avatar

Upload a JPEG, PNG, or WebP image up to 2 MB. Adjust the circular crop and zoom, then upload. Use **Show avatar** and **Save changes** to control whether it appears on the public profile. You can replace or remove it later.

The public avatar is separate from the account photo shown in the sidebar account menu.

## Choose visitor options

| Option | Effect |
| --- | --- |
| **Visitor validation** | Requires a visitor introduction before Chat continues; when disabled, an introduction can remain optional. |
| **Allow interpretation** | Permits labeled interpretations and general knowledge alongside answers grounded in published Memory. |
| **Public CV** | Shows or hides the CV panel. Hiding the panel does not remove the CV from published Memory. |
| **Starter prompts** | Supplies suggested questions for visitors to begin a conversation. |

No option gives visitors access to Private documents or drafts. Interpretation cannot turn an inference into a claim about your personal history.

## Write the welcome copy

Edit the public **Header**, **Chat**, and **Fast Check** copy in their respective tabs. English and Russian variants let you set the titles, descriptions, and starter prompts for each language.

Tell visitors whose profile they are exploring, what they can ask, and what the answer can help them understand. Avoid implying that the twin can accept a role, negotiate, or make decisions for you. Save the changes and inspect the public page in the languages you use.

## Add professional links

Use **Social links** for LinkedIn, Telegram, GitHub, X, a website, Cal.com, Instagram, or another supported HTTPS destination. Check the URL and label before saving.

A Cal.com or other calendar link opens an external scheduling page. To let Public Chat offer an embedded booking form, separately [connect Cal.com meetings](/settings/meetings) in **Settings**.

## Models and integrations

**Settings** contains Cal.com and optional bring-your-own-key model controls. When using your own model configuration, choose which models visitors can see and the provider-routing preference there. See [Integrations and models](/settings/integrations).

Use [saved shares](/sharing) when you want to expose one completed result instead of ongoing access to the active twin. Review and revoke those links separately.
