**Settings** contains optional model and service connections for your [Profile](/profile). You can use TLDT's available hosted configuration or enable **BYOK** (bring your own key) for supported providers. Integration settings do not change which Memory you have approved for publication.

## Hosted access and BYOK

With BYOK off, supported actions use TLDT's hosted provider configuration and available models. You do not need to supply your own keys to begin when hosted services are available.

With BYOK on, connect the keys required for your workflows:

- **OpenRouter** for model generation, including Chat, preparation, and Memory actions.
- **Firecrawl** for supported document conversion, vacancy-link extraction, and research tasks that use it.
- **Perplexity** for supported external research.

Use the provider card's key link, enter the key, and connect it. Check the connection status and any displayed balance. Review the model list, public visibility choices, and routing preference, then save changes where offered. **Low Price** and **High Throughput** express a routing preference, not a guaranteed cost or response time.

BYOK uses your connected credentials and does not silently fall back to TLDT's hosted keys when one is missing or fails. Provider usage can incur charges on your account. Disconnect or replace a key through its provider card.

Credentials stay out of public answers and transcripts. Paste a key only into its dedicated connection field, never into Memory or a chat message.

## Documents, vacancies, and research

Document conversion makes supported [CV](/profile#add-your-cv) and [Raw uploads](/memory/import-guide#if-you-are-starting-with-documents) readable as text. Check the extracted result before publishing it. Vacancy extraction and research help supply role or company context; they do not verify your career history.

[Job Search](/jobs/search) reads a vacancy catalogue. [Saving a role](/jobs/saved-vacancies) keeps a vacancy snapshot; it does not add the listing to your career evidence or submit an application.

If a vacancy URL cannot be read, paste its description into [Fast Check](/public-profile/fast-check#run-an-owner-fast-check) or [Simulate](/owner-review/simulate#set-up-an-interview). If conversion fails, use an accurate Markdown or text version where supported.

## Meetings

[Cal.com meetings](/settings/meetings) has its own connection and enabled switch in Settings. It lets the twin offer a visible booking form with live availability. Adding a calendar URL under [Profile's social links](/settings/public-link#add-professional-links) is a separate action.

## Voice input

The microphone uses speech-to-text to return a recording as editable text. Review the transcript and send it yourself in [Chat](/public-profile/chat#voice-input) or [Manual Simulate](/owner-review/simulate#voice-and-assisted-drafting). In a [Memory Gap](/memory/gaps#add-your-answer), the text is appended to **Your answer** and saved through that field's normal autosave.

Voice input does not automatically submit a message, generate Memory, or publish a change. Recording and transcription failures leave the existing text intact. It is not a realtime voice interviewer or a general audio-file import.

## Browser assistants and documentation access

In a compatible browser, TLDT exposes page-scoped **WebMCP** actions. On a public profile, an assistant can use the currently open profile's permitted capabilities. In the authenticated owner workspace, supported actions remain bound to your account, and sensitive operations use visible confirmation or the ordinary UI.

This is not a remote account connector that you can install in ChatGPT or Claude to continuously read and update Memory. Use [Import Guide](/memory/import-guide) for the current assistant-to-TLDT export workflow. [Memory Loop](/memory/loop) answer authoring and proposal review stay in the visible TLDT interface.

The documentation site's contextual menu can also connect assistants to the documentation search MCP. That connection searches these help pages; it does not grant access to your TLDT account or career Memory.
