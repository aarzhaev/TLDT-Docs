Instant Fit is a private first assessment of a vacancy against your CV and selected published Memory. Use it to prioritize what to read and investigate. Use [Fast Check](/public-profile/fast-check) when you want a fuller diagnostic for one role.

## Before you start

Sign in, [publish a reviewed CV and prepare Search Profile](/profile). More relevant published Memory can give the assessment better evidence than a CV alone. Your public link does not need to be enabled.

## Check a list of jobs

1. Open **[Job Search](/jobs/search#search-and-filter)** and set your query and filters.
2. Turn on **Instant Fit** beside Filters.
3. Watch results arrive as vacancies are checked. The progress shows processed roles and matches.
4. Filter by a result category, or use **Best fit** or **Posted newest** after the run finishes.
5. Open a promising vacancy to inspect the reasons, then continue to [Fast Check](/public-profile/fast-check) or [Simulate](/owner-review/simulate).

The personalized search checks a limited candidate set, not every vacancy in the catalogue. **Low match** results are hidden from this grid. Turning Instant Fit off cancels new work and returns to ordinary search; checks already underway may still complete. An interrupted run can retain partial results and offer a retry.

## Understand the labels

The list and detail view use different short labels for the same outcomes:

| Job-list label | Detail label | How to use it |
| --- | --- | --- |
| Recommended | Strong | Several core factors have strong support. Read the full role and check practical constraints. |
| Possible | Worth | Evidence is mixed, but the role is worth a closer look. |
| Need more info | Unclear | There is not enough reliable evidence for a clear recommendation. |
| Low match | Skip | Evidence shows a role-direction or important requirement mismatch. Hidden in personalized search results. |

An **Incomplete** result means the vacancy itself lacks enough usable detail. **Unavailable** means the check could not complete. Neither is a negative judgment about your experience.

## Inspect one vacancy

Opening a vacancy detail loads an existing compatible result or runs a check when the required profile is ready. Expand **Instant Fit** to review **Strong signals**, **Watch-outs**, and **Missing evidence**. The detail explanation also shows how the assessment was reached.

The assessment considers role and career direction, responsibilities, seniority and scope, skills and methods, transferable domain experience, location and work arrangement, must-have requirements, and evidence for an interview conversation.

Missing evidence is different from an explicit mismatch. A percentage shown in the detailed explanation concerns an individual assessment; it is not your probability of getting an interview or being hired.

## When your evidence changes

Both list and detail checks use the evidence selection saved with Search Profile. Return to **[Profile → Search profile → Context](/profile#choose-the-context)** to change that selection, then update the profile.

A result opened from an earlier search can retain that search's profile version. Read any previous-profile notice. Start an updated search when you want the newly published evidence to affect the results.

If the context is too large, use **Review sources** to choose fewer complete Memory documents. If no published CV is available, [add one in Profile](/profile#add-your-cv). An error or stale profile never becomes a guessed fit result.
