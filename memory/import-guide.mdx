If ChatGPT or Claude already knows your professional history, use that context to bootstrap TLDT. **Import Guide** provides a ready-made export prompt and an upload area for the resulting Memory files. You still review the facts and decide what to publish.

## Export the context your assistant can access

<Steps>
  <Step title="Open Import Guide in TLDT">
    Choose **Open in ChatGPT**, **Open in Claude**, or **Copy prompt**. The assistant buttons open a chat with the prompt prefilled; Copy prompt lets you paste the complete instructions into a conversation or project with useful career context.
  </Step>
  <Step title="Run the prompt and inspect the output">
    Ask the assistant to use only the professional information actually available to it. The prompt requests focused career files and three [representation files](/memory/overview#special-roles): `soul.md`, `boundaries.md`, and `voice.md`.

    Check roles, dates, responsibilities, metrics, ownership, and limitations. Remove invented details and material you do not want retained. The assistant's output is a draft, not independent verification of your history.
  </Step>
  <Step title="Save the Markdown files">
    Download each `.md` file if the assistant can create files. Otherwise, save each complete file block under the filename it provides, keeping the [Properties](/memory/drafts-and-documents#documents-and-properties) block at the top.

    After the main export, the prompt asks the assistant to offer deeper files where it has supporting evidence. Request only the additional cases or examples you want.
  </Step>
  <Step title="Upload into Derived Memory">
    Drop the `.md` files into Import Guide, or use **Upload** in Memory's **Derived** column. Upload up to 20 files at a time, with a 2 MB limit per file and 4 MB per batch. Repeat for the remaining files.
  </Step>
  <Step title="Review and publish deliberately">
    Open the imported cards in **[Memory](/memory/overview#the-memory-workspace)**. Review their text, visibility, sensitivity, and special roles. The guide asks the assistant to mark files Private. Check those Properties yourself, then mark the documents you approve Public and [publish the reviewed version](/memory/publish).
  </Step>
</Steps>

This workflow does not import a ChatGPT or Claude account archive, connect the accounts, or continuously synchronize their memory. A new assistant chat may not have access to all your older conversations. If relevant context is missing, provide sources you can verify or use a conversation where it is available.

## If you are starting with documents

Upload your [CV in Profile](/profile). Add project notes, transcripts, work samples, or other supporting evidence through **Memory → Raw → Upload**, or [create a Raw note](/memory/drafts-and-documents#draft-workspaces) directly.

| Destination | Accepted files |
| --- | --- |
| Profile CV upload | PDF, DOC, DOCX, ODT, RTF, HTML, MD, TXT; one file up to 2 MB. |
| Raw Memory | PDF, DOC, DOCX, ODT, RTF, HTML, HTM, MD, TXT; up to 20 files, 2 MB each and 4 MB per batch. |
| Derived Memory and Import Guide | Markdown `.md` files; the same Memory batch limits apply. |

Rich-document uploads are converted to text. Review the extracted content, especially tables, dates, and numbers. A parsing or Properties error needs review or retry; uploading does not establish that the content is accurate or live.

Use [Derived generation](/memory/generate-derived) to organize selected Raw sources. Keep unrelated topics separate and retain source material you need for later fact checking.

<Tip>
  A CV and a few accurate examples are enough to begin. Use real vacancies and [Memory Gaps](/memory/gaps) to identify the next useful question instead of trying to reconstruct your entire career at once.
</Tip>
