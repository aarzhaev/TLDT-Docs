Start from the real role or conversation you need to prepare for. Add the smallest set of sources that can support an honest first check; expand the Memory when a concrete question exposes missing proof.

## What to add first

- your current CV or résumé;
- project notes with dates, outcomes, constraints, and your exact role;
- work-history notes that explain scope or decisions beyond a résumé bullet;
- interview transcripts or work samples you own;
- a short statement of preferred roles, working style, and boundaries;
- supporting material for a project you expect to discuss.

Keep unrelated topics in separate files. Focused sources are easier to review, retrieve, and correct.

## Add sources to Raw Memory

<Steps>
  <Step title="Choose a draft">
    Select the workspace you want to update. Create an empty draft, copy another draft, or copy an immutable published version.
  </Step>
  <Step title="Upload supported files">
    Add Markdown or text files through the Raw column. TLDT stores the content separately from its server-owned Properties.
  </Step>
  <Step title="Review Properties analysis">
    TLDT can propose a title, summary, topics, and retrieval hint with the selected model. Treat every proposal as a draft.
  </Step>
  <Step title="Set visibility and sensitivity">
    Choose **Public** only when the source is eligible for the next publication. Keep material **Private** when it should remain in the owner workspace.
  </Step>
  <Step title="Check the evidence">
    Confirm dates, actors, scope, metrics, denominators, limitations, and source ownership before relying on the document.
  </Step>
</Steps>

## What import does not do

TLDT does not crawl arbitrary accounts, automatically build a complete career history, decide which claims are true, or publish uploaded material. Adding a source creates reviewable Raw Memory; it does not make the source part of the active public representation.

<Warning>
  Never use generation to fill an evidence gap. If a source does not support a claim, keep the gap visible or add a source you own and can review.
</Warning>
