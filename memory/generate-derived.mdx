Derived generation turns selected Raw evidence into a reviewable Markdown candidate. Use it to organize accurate source material for retrieval and conversation, keeping facts and limitations intact.

Every candidate from this flow starts Private and keeps links to its sources. It becomes usable by runtime workflows after you review, save, mark it Public, and [publish the version](/memory/publish#publish-the-reviewed-version). Memory's Publish action also activates that version.

For [saved answers to Memory Gaps](/memory/gaps#add-your-answer), use the separate [Memory Loop](/memory/loop) flow. For ready-made Markdown files from ChatGPT or Claude, use [Import Guide](/memory/import-guide).

## Generate a candidate

<Steps>
  <Step title="Select up to 20 Raw documents">
    Open **Generate Derived Memory** from the Derived column and choose only the sources needed for one topic. Focused selections make factual review easier.
  </Step>
  <Step title="Choose a preset or custom instruction">
    Ask for a specific artifact, such as project context, a role summary, or an explanation of a decision and its constraints.
  </Step>
  <Step title="Choose the exact model and target path">
    TLDT uses the [model you select](/settings/integrations#hosted-access-and-byok). The output receives a target path and keeps links to its Raw sources.
  </Step>
  <Step title="Review the Private candidate">
    Check every date, actor, metric, denominator, time range, claim of ownership, outcome, limitation, and uncertainty.
  </Step>
  <Step title="Save through the normal document flow">
    Keep the candidate [Private](/memory/drafts-and-documents#documents-and-properties) until you are comfortable making it eligible for publication.
  </Step>
</Steps>

## Generation limits

Generation does not:

- publish or activate a Memory version;
- mark a document Public;
- invent missing facts or strengthen weak evidence;
- convert team work into individual ownership;
- silently choose a different model;
- silently truncate selected sources;
- reconcile contradictions across your entire Memory;
- run the separate gap-answer Memory Loop automatically.

If the selected context is too large, TLDT returns a context-overflow error rather than silently dropping source material.

<Note>
  Generation helps with organization. The owner supplies authority through evidence, review, and explicit publication.
</Note>
